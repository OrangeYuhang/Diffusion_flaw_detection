# 中期答辩 PPT 设计方案 — DefectDiffu

## 背景

基于 DefectDiffu 项目（ECCV 2024，Few-shot Defect Image Generation based on Consistency Modeling）的中期答辩演示。听众为混合型（导师+同学），15-20分钟，30页。

**不包含** DiTMaskConditioned 模型部分，聚焦标准 DiT 文本引导模型。

## 叙事策略

三个模块各一个核心亮点，形成完整叙事线：
- **模块1**: DiT 交叉注意力机制同时生成缺陷图像和精准分割掩码（双输出创新）
- **模块2**: CFG + 多轴多样性生成高质量可控样本
- **模块3**: 合成数据确实能提升 PatchCore 检测性能（实用价值验证）

## 关键数据来源

- 训练损失: `loss_log_mask_cond.csv`（标准DiT收敛趋势相同，最终loss~0.3）
- 生成样本: `test.py` 输出目录 `./img/`
- 实验评估: `anodetection/experiments/` 下的 batch_eval_v2.py, supervised_eval_v2.py
- 损失分量: mse, vb, mask_mse, mask_dice, att_align

- 文字内容以中文为主，专业术语保留英文
