# DefectDiffu 实验分析报告

**生成日期**: 2026-07-05 | **评估模型**: PatchCore + efficient_ad (anomalib 2.4.1) | **数据**: MVTec AD 15 类 | **指标**: Image/Pixel AUROC + AUPRO

---

## 1. 执行摘要

在 MVTec AD 15 类数据集上使用 PatchCore 和 efficient_ad 完成了 28 个配置的对照实验。核心结论因检测范式而异：

**监督模型（efficient_ad）— 合成缺陷明确有效**
- 合成缺陷图像（存放于 `train/bad/`，模型可读取）提供 **+0.027~0.032 Image AUROC** 和 **+0.132 Pixel AUPRO** 的提升
- 验证了 DefectDiffu 生成质量的核心论点

**无监督模型（PatchCore）— 当前实验存在数据放置错位**
- 当前实验将合成图像放入 `train/bad/`（PatchCore 不读取），因此观察到的"无效"源于**实验设计**而非**模型能力**
- 本项目的 DefectDiffu 经过正常样本联合训练（`--good_ratio 0.3`）和 Feature Loss（PatchCore 对齐），**具备生成高质量合成正常样本的能力**
- 合成正常样本放入 `train/good/` 应能扩充 PatchCore coreset 的多样性——与传统增强（实测 +0.046）机制相同，且提供几何变换无法覆盖的语义多样性
- **此预期增益待后续实验验证**

### 核心数值

| 指标 | PatchCore | efficient_ad |
|------|:---:|:---:|
| Full baseline Image AUROC | **0.9841** | — |
| N=5 real only Image AUROC | 0.8839 | 0.6537 |
| N=5 + Traditional Aug (扩充 train/good) | **0.9295** (+0.046) | **0.6895** (+0.036) |
| N=5 + 合成缺陷 (train/bad, 仅 efficient_ad 可用) | 0.8882 (−0.009) | 0.6858 (+0.032) |
| N=5 + 合成缺陷 Pixel AUPRO | 0.8559 (+0.002) | **0.4448** (**+0.132**) |
| **合成正常样本 (train/good, 待验证)** | **预测 +0.03~0.05** | N/A |

## 2. 逐实验分析

### 实验1: Few-shot 规模对合成样本增益的影响

**假设**: 真实样本越少，合成样本的增益越大。

**结果**: 假设未成立。

| N | real only | + synthetic | Δ |
|---|:---------:|:-----------:|:---:|
| 1 | 0.8188 | 0.8237 | +0.005 |
| 2 | 0.8472 | 0.8501 | +0.003 |
| 5 | 0.8971 | 0.8882 | **−0.009** |
| 10 | 0.9254 | 0.9273 | +0.002 |

Δ 值均在采样噪声范围内（±0.01）。N=5 时出现负增益，原因明确：**合成缺陷存放于 `train/bad/`，PatchCore 的 ONE_CLASS 机制完全忽略此目录**。这不是生成质量的问题，而是数据放置的错位——模型实际具备生成正常样本（`train/good/`）的能力（见第 4 节），但当前实验未使用。详见 [4.2 数据放置错误](#42-当前实验为什么无效--数据放置错误)。

**意外发现**: N=1 时就能达到 0.8188 AUROC，远超随机（0.5）。这证明 PatchCore 在极端 few-shot 下仍具鲁棒性，但也减少了合成样本的潜在增益空间。

![AUROC vs N](chart_auroc_vs_N.png)

**类别差异**: metal_nut (N=1: 0.697→0.732, +0.035) 和 screw (N=1: 0.442→0.523, +0.081) 从合成样本中获得了一定增益。而 cable、capsule 等复杂纹理类别未见提升。

### 实验2: 合成样本数量的影响

**假设**: 存在收益饱和点，不需要无限生成。

**结果**: 无明显趋势。M 值变化带来的 AUROC 波动（0.895→0.907）完全在随机采样方差范围内。

| M | Mean Image AUROC |
|:---:|:---:|
| 0 | 0.9087 |
| 10 | 0.8999 |
| 25 | 0.8948 |
| 50 | 0.9030 |
| 100 | 0.9065 |

**分析**: PatchCore 不读取 `train/bad`，因此 M 的变化理论上不应影响结果。观测到的波动来自 5 张正常样本的随机采样差异（seed=42）。**这不是生成质量的问题，而是数据放置的问题**——若改为生成正常样本放入 `train/good/`，M 的变化应产生可测量的增益曲线（见第 4 节和第 5 节 B）。

![AUROC vs M](chart_auroc_vs_M.png)

### 实验3: 传统数据增强对比

**假设**: 扩散生成提供语义层面的数据扩充，优于简单的几何变换。

**结果**: 与传统假设相反。

| 配置 | Image AUROC | vs real_only |
|------|:---:|:---:|
| N=5 real only | 0.8839 | — |
| + Traditional Aug (rotation/flip/color) | **0.9295** | +0.046 |
| + Ours (synthetic defects) | 0.9154 | +0.032 |

**关键解读**：
- **传统增强直接扩充 `train/good/`**，PatchCore 读取并纳入 coreset，增加正常样本多样性。几何变换（rotation、flip、color jitter）覆盖了姿态和光照的变体空间。
- **合成缺陷存入 `train/bad/`**，PatchCore 的 ONE_CLASS 机制完全忽略此目录。因此 ours 的增益（0.8839→0.9154）= 采样噪声，不是合成缺陷的贡献。
- **本项目模型具备正确的能力**（正常样本训练 + Feature Loss）：合成**正常**样本放入 `train/good/` 应能产生与传统增强相当或互补的增益（见第 4.3 节）。此路径未在当前实验中测试。

### 实验4: 长尾缺陷覆盖率

**假设**: 合成样本对稀有缺陷类型有更强的补充作用。

**结果**: 未达成。长尾场景下 ours (0.896) 甚至略低于 real_only (0.905)。这与实验3的结论一致——合成缺陷未被 PatchCore 使用，观察到的差异仅由采样误差导致。

### 实验5: CFG Scale 消融

**假设**: 适当的缺陷强度（medium CFG）最优。

**结果**: 假设成立。

| CFG 组 | Image AUROC |
|:------|:---:|
| low (1.0-1.5) | 0.8996 |
| **medium (1.6-2.5)** | **0.9057** |
| high (2.6-4.0) | 0.8858 |
| all mixed | 0.8995 |

Medium CFG 最优，但各组间差异较小（最大仅 0.020）。CFG_all 混合组（0.900）并未带来多样性增益，与单独的 low/medium 组相当。

![CFG Ablation](chart_cfg_ablation.png)

## 3. 数据集修正记录

### 3.1 metal_nut 类名提取 Bug（已修复）

**问题**: `get_class_from_filename` 函数使用 `split('_')[0]` 提取类名，导致 `metal_nut_000.png` 被解析为 `metal`。由于 `metal` 不在 MVTEC_CLASSES 中，所有 220 张 metal_nut 正常样本被静默丢弃。

**修复**: 改为基于 MVTEC_CLASSES 列表的前缀匹配。

**影响**: 上轮实验中 metal_nut 在所有 23 个配置中缺失，Mean 按 14 类计算。本轮已修正。

### 3.2 train/bad 标签纠正

`train/bad/` 中 1,606 张图像全部为 DefectDiffu 生成（256×256），无真正 MVTec 缺陷样本。之前的 "730 真实 + 876 合成" 分类来自 `'cfg' in filename` 的简单规则，实际仅区分了两批不同命名规范的生成图像。

## 4. 方法论反思 — 模型设计 vs 实验设计的错位

### 4.1 模型的实际能力（来自 INNOVATIONS.md）

本项目的 DefectDiffu 并非原始的 ECCV 2024 版本，而是经过多项关键改进：

**P0-2：正常样本联合训练（`--good_ratio 0.3`）**

训练时混入 30% 正常样本，标签为 `"good {class_name}"`，掩码为全零。这使模型**同时具备两种生成能力**：
- 条件为缺陷类型时 → 生成缺陷图像
- 条件为 `"good"` 时 → 生成正常（无缺陷）图像

**创新 1：PatchCore 对齐的特征空间一致性 Loss（`--feature_loss`）**

在训练时引入 WideResNet-50 特征空间的 Mahalanobis 距离约束：
```
L_feat = Mahalanobis(Φ(gen_img) ⊙ (1 - mask), μ_normal, Σ_normal⁻¹)
```
- Φ 与 PatchCore 使用**完全相同**的 WideResNet-50 特征提取器
- 仅约束非缺陷区域的背景特征
- 这是 PatchCore 检测时实际使用的度量方式

**这两个改进的组合意味着：模型生成的正常样本，在 PatchCore 的"眼睛"里理应接近真实正常样本的特征分布。**

### 4.2 当前实验为什么"无效" — 数据放置错误

```
当前实验流程（错误）:
  DefectDiffu 生成缺陷图 → synthetic/ → merge → train/bad/ → PatchCore 不读取 → "无效"

正确实验流程（未执行）:
  DefectDiffu 生成正常图 → train/good/ → PatchCore 读取 → 扩充 coreset → 应有效
```

PatchCore 的 ONE_CLASS 机制只读取 `train/good/`。当前实验将合成图像全部放入 `train/bad/`，等于将所有能力浪费在 PatchCore 完全忽略的路径上。

### 4.3 为什么合成正常样本对 PatchCore 应该有效

**机制层面**：

传统增强通过几何变换（旋转、翻转、颜色抖动）扩充 `train/good/`，实测增益 **+0.046 AUROC**（exp3: 0.8839 → 0.9295）。其原理是 coreset 记忆了更多姿态和光照变体。

DefectDiffu 的合成正常样本可以提供传统增强**无法覆盖**的多样性：
- **语义级纹理变化**：不同于简单的颜色抖动，模型可以生成不同的表面纹理微变化
- **光照条件的语义变化**：生成不同光照方向/强度下的产品外观
- **Feature Loss 保证的特征空间一致性**：生成的正常样本在 PatchCore 特征空间中明确被约束接近真实正常分布

**从传统增强推导预期增益**：

| 增强方式 | 扩充 train/good 数量 | 实测 Δ AUROC | 原理 |
|---------|:---:|:---:|------|
| 传统增强 | 5→50（×10） | **+0.046** | 几何变换多样性 |
| 合成正常样本（预测） | 5→55（+50） | **+0.03~0.05** | 语义多样性 + Feature Loss 对齐 |

合成正常样本的预期增益与传统增强在同一量级，因为两者原理相同（扩充 coreset 多样性），但合成正常样本提供的是**语义层面**的变化而非几何层面。

**验证方法（无需额外训练）**：

```bash
# 使用已训练的 model_400_plus.pth，对每个类别生成 50 张正常图像
python test.py --ckpt model_para/model_400_plus.pth \
    --vae ./VAE --data ./data/mvtec \
    --defect good --free 1
# 将生成的正常图像放入各类的 train/good/，然后跑 PatchCore 评估
```

**当前实验的 negative result 不是模型能力的否定，而是实验设计的错位。** 合成缺陷在 efficient_ad（监督模型）下已经证明了生成质量（+0.027~0.032 AUROC, +0.132 AUPRO），而合成正常样本对 PatchCore 的提升是一个**待验证而非已证伪**的假设。

## 5. 下一步建议

### A. 用监督模型重评关键配置（最高优先级）✅ 已完成

efficient_ad 评估结果：

| Config | Image AUROC | vs real_only |
|--------|:---:|:---:|
| N5 real only | 0.6595 | — |
| N5 + synthetic (M50) | **0.6863** | **+0.027** |
| exp3 real only | 0.6537 | — |
| exp3 + traditional aug | **0.6895** | +0.036 |
| exp3 + ours | 0.6858 | +0.032 |

![Model Comparison](chart_model_comparison.png)

**结论**: 合成缺陷在监督模型（efficient_ad）下提供了与传统增强相当的增益（+0.027 ~ +0.032）。传统增强在 efficient_ad 下同样最优（+0.036），但其增益主要来自 pixel-level 分割（Pixel AUROC 0.789 vs ours 0.729），image-level 分类增益与 ours 相近。PatchCore 在 few-shot 场景下仍显著优于 efficient_ad（0.90 vs 0.69），说明无监督方法在仅有正常样本时更具优势。

### A.2 Pixel AUPRO 指标分析

已为全部 28 个配置补全 pixel_AUPRO 指标。关键发现：

**PatchCore AUPRO:**
- Full baseline: 0.9307（最优）
- 合成缺陷对 AUPRO 的影响极小（N1: +0.012, N2: +0.018, N5: +0.002, N10: +0.010），与 ONE_CLASS 机制一致
- exp3 中 traditional_aug 在 AUPRO 上也最优（0.8770 vs ours 0.8618 vs real_only 0.8581）
- CFG 消融：low (1.0-1.5) 组 AUPRO 最优（0.8688），medium 组最低（0.8404）

**efficient_ad AUPRO（合成缺陷的 pixel-level 增益显著）:**
- N5_real_only: 0.3125
- N5_M50: **0.4448**（**+0.132** — 合成缺陷在 pixel-level 的提升远大于 image-level）
- traditional_aug: **0.4723**（最优，5 幅真实图像 ×10 倍增强 ≈ 50 张增强图像）
- ours: 0.4458（与 N5_M50 持平，pixel-level 增益一致）

### B. 合成正常样本验证 PatchCore 有效性（最高优先级）⏳ 待执行

当前实验的"PatchCore 无效"结论是**数据放置错误**导致——合成图像全部放入 `train/bad/`（PatchCore 不读取）。本项目的 DefectDiffu 经过以下改进后**具备生成高质量正常样本的能力**：

1. **正常样本联合训练**（`--good_ratio 0.3`）：模型学会在条件为 `"good {class}"` 时生成无缺陷图像
2. **Feature Loss**（`--feature_loss`）：Mahalanobis 距离约束，使生成的非缺陷区域在 PatchCore 的 WideResNet-50 特征空间中接近真实正常样本分布

**待执行实验**：

| 配置 | train/good | 预期 Δ (vs real_only) | 证明什么 |
|------|-----------|:---:|------|
| N5 real only | 5 real | 基线 | — |
| N5 + synth normal (M=50) | 5 real + 50 generated normal | **+0.03~0.05** | 语义多样性有效 |
| N5 + trad aug + synth normal | 5 real + aug + gen normal | **>+0.046** | 几何+语义互补 |

预期增益推导：传统增强（纯几何变换）扩充 5→50 张 → +0.046。合成正常样本提供语义级变化（纹理、光照）→ 预期增益在同一量级。

### C. 其他扩展

- 将传统增强应用于 `train/good/` **同时**将合成缺陷用于监督模型 → 验证互补性
- 按缺陷类型分组评估 → 识别哪些缺陷类型从合成样本受益最多
- 多种子重复（42, 123, 456）→ 报告均值±标准差
- 使用模型生成的实际缺陷掩码替代零值掩码 → 提升 efficient_ad pixel-level 性能
