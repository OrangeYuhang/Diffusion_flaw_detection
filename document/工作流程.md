## 阶段一：标准 DiT 微调

### 目标

在 DiT-XL/2 预训练权重基础上，用 MVTec AD 数据集微调，获得能根据文本 prompt 生成缺陷图像+掩码的模型。

### 前置条件

| 资源 | 路径 | 状态检查 |
|------|------|----------|
| DiT-XL/2 预训练权重 | `./DiT-256/DiT-XL-2-256x256.pt` | 下载自 Facebook |
| SD VAE 权重 | `./VAE/` | `config.json` + `.safetensors` |
| MVTec AD 数据集 | `./data/mvtec/` | 15 类产品，含 train/test/ground_truth |
| Conda 环境 | `environment.yml` | Python 3.10 + PyTorch 2.12 + CUDA 12.8 |

### 命令

```bash
# 全优化训练（推荐）
python train.py \
    --ckpt ./DiT-256/DiT-XL-2-256x256.pt \
    --batchsize 2 \
    --vae ./VAE \
    --data ./data/mvtec \
    --good_ratio 0.3 \
    --feature_loss \
    --feature_loss_freq 50
```

### 训练过程

```
Epoch 0-100:   基础收敛（fg/bg 分离 loss + Dice mask loss + 注意对齐 loss）
Epoch 50-1500: 特征空间一致性 loss 加入（每 50 epoch），约束非缺陷区域分布
每 100 epoch:  自动保存 checkpoint/model_{epoch}.pth
最终:          使用 model_para/model_1500.pth（或最优 epoch）
```

### 输出

| 产出 | 说明 |
|------|------|
| `checkpoint/model_*.pth` | 训练中周期性检查点 |
| `model_para/model_1500.pth` | 最终模型（移至 model_para/） |
| `img/loss_curve.png` | 损失曲线图 |

### 验证

```bash
python test_gen.py  # 单图生成，人工检查质量
# 或
python test.py --ckpt ./model_para/model_1500.pth --vae ./VAE --data ./data/mvtec
# 为全部类别/缺陷类型生成图像
```

## 阶段二：下游检测消融实验

### 目标

用定量数据（AUROC、F1-score）证明 DefectDiffu 生成的合成缺陷样本能提升 PatchCore 检测性能。

### 实验设计（5 组对照）

#### 实验 A：Few-shot 消融

| 组 | 训练集 | 目的 |
|----|--------|------|
| 对照组 | 仅 MVTec 原始正常样本 | 基线检测性能 |
| 实验组 1 | 原始正常 + 1-shot 真实缺陷 | 少量真实样本基线 |
| 实验组 2 | 原始正常 + DefectDiffu 合成缺陷 | 合成数据能否替代真实 |
| 实验组 3 | 原始正常 + 1-shot 真实 + 合成缺陷 | 合成+真实联合效果 |

#### 实验 B：合成样本数量扫描

| 组 | 合成样本数/类 | 目的 |
|----|--------------|------|
| B1–B5 | 5 / 10 / 20 / 50 / 100 | 找到性价比最优的生成数量 |

#### 实验 C：与传统数据增强对比

| 组 | 增强方法 |
|----|----------|
| C1 | 旋转/翻转/颜色抖动 |
| C2 | CutMix / CutPaste |
| C3 | DefectDiffu 合成 |

#### 实验 D：长尾类别覆盖

证明合成数据对 MVTec 中样本量少的类别（如 tile、wood）提升更显著。

#### 实验 E：生成质量消融

| 组 | 模型变体 | 目的 |
|----|----------|------|
| E1 | 原始 loss（无优化） | 消融 fg/bg 分离 loss |
| E2 | 无 Dice loss | 消融 Dice mask loss |
| E3 | 无正常样本 | 消融 good_ratio |
| E4 | 全优化 | 最终模型 |

### 执行方式

**方式 1：闭环自动化**（`adaptive_generate.py`）
```bash
python adaptive_generate.py \
    --ckpt ./model_para/model_1500.pth \
    --vae ./VAE \
    --data ./data/mvtec \
    --num_iterations 3 \
    --total_budget 200
```

**方式 2：手动分步**
```bash
# 步骤 1：生成合成缺陷
python test.py --ckpt ./model_para/model_1500.pth --vae ./VAE --data ./data/mvtec

# 步骤 2：构建 anomalib 数据集
python prepare_dataset.py

# 步骤 3：运行 PatchCore 训练+评估
# (使用 anomalib 命令行或脚本)

# 步骤 4：对比分析
```

### 输出

| 产出 | 说明 |
|------|------|
| 实验记录表格 | 各组 AUROC / F1-score / AP |
| 消融对比图 | 柱状图/折线图 |
| `adaptive_output/auroc_history.json` | 闭环迭代记录 |

### 期望结论

"DefectDiffu 合成数据在 N 个 MVTec 类别上将 PatchCore AUROC 提升 X%，在少样本场景下接近完全监督性能。"

## 阶段三：掩码条件训练 + GUI 演示

### 目标

训练 `DiTMaskConditioned`，使模型能根据用户指定的空间掩码在特定位置生成缺陷，并集成到 Gradio 交互界面演示。

### 3A：训练 DiTMaskConditioned

```bash
python train_mask_condition.py \
    --ckpt ./model_para/model_1500.pth \
    --batchsize 2 \
    --vae ./VAE \
    --data ./data/mvtec \
    --good_ratio 0.3
```

**关键差异**：用阶段一的 `model_1500.pth` 初始化 DiT 基类权重（`strict=False`），`MaskEncoder`/`mask_fusion`/`mask_to_tokens` 层随机初始化，用 ground_truth 掩码监督训练。

输出：`checkpoint/model_mask_cond_final.pth`

### 3B：启动 GUI

```bash
python app.py
```

操作步骤：
1. 选择模型类型 → **掩码条件 DiT**
2. 加载 `checkpoint/model_mask_cond_final.pth`
3. 选择掩码模式：
   - 随机斑点 / 随机线条 / 随机噪声 → 自动生成随机位置
   - 手绘/上传 → 在画布上指定精确位置
4. 输入缺陷类型（含强度描述，如 "严重划痕"）
5. 点击生成

### 输出

| 产出 | 说明 |
|------|------|
| `checkpoint/model_mask_cond_final.pth` | 训练好的掩码条件模型 |
| GUI 录屏/GIF | 演示"输入文本+绘制位置→生成缺陷" |

## 阶段四：一致性蒸馏

### 目标

将 50 步 DDPM 采样蒸馏为 4 步，实现快速采样，同时保持生成质量。

### 命令

```bash
python consistency_distill.py \
    --teacher_ckpt ./model_para/model_1500.pth \
    --vae ./VAE \
    --data ./data/mvtec \
    --num_student_steps 4 \
    --num_epochs 50 \
    --batchsize 4
```

### 注意

- 蒸馏对象是**标准 DiT**（阶段一输出），不是 `DiTMaskConditioned`
- 蒸馏后输出 4 步采样器，生成速度约 12× 提升
- 如果 GUI 需要快速采样，可加载蒸馏模型到 app.py（当前需手动切换代码）

### 输出

| 产出 | 说明 |
|------|------|
| `checkpoint/distilled.pth` | 蒸馏后的学生模型 |
| 速度对比数据 | 50 步 vs 4 步耗时 + FID/质量对比 |
